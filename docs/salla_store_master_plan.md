## 📋 تفاصيل المراحل وخطوات التنفيذ

### 🔹 المرحلة 1: تجميع البيانات والتأسيس (Discovery & Setup)
- [ ] تحديد نشاط المتجر ونوع المنتجات بدقة.
- [ ] معرفة نوع باقة سلة (سلة بلس / سلة برو).
- [ ] طلب بيانات الدخول للوحة التحكم أو دعوة كمدير للمتجر (Staff).
- [ ] حصر بيانات التوثيق (وثيقة عمل حر / سجل تجاري، الآيبان البنكي، الهوية).

---

### 🔹 المرحلة 2: الهوية البصرية وتصميم الجرافيك (Visuals & Branding)
> **ملاحظة:** سيتم حفظ كافة التصاميم والبانرات في المجلد `D:\salla\designs`.
- [ ] تحديد لوحة الألوان (Color Palette) والخطوط المناسبة للهوية.
- [ ] تصميم/تحسين الشعار (Logo) والأيقونة المصغرة (Favicon).
- [ ] تصميم البانر الرئيسي المتحرك للواجهة (Hero Banners) - مقاس `1920x600 px` أو `1200x500 px`.
- [ ] تصميم بانرات العروض الترويجية والخصومات (Promo Banners).
- [ ] تصميم أيقونات الأقسام والمميزات (مثل: شحن سريع، دفع آمن، أصلي 100%).
- [ ] تجهيز ومعالجة صور المنتجات بجودة عالية وخلفيات متناسقة.

---

### 🔹 المرحلة 3: الإعدادات والصفحات القانونية (Core Settings & Compliance)
> **ملاحظة:** سيتم حفظ نصوص الصفحات في المجلد `D:\salla\content`.
- [ ] ضبط بيانات المتجر (اسم المتجر، الوصف التعريفي، قنوات التواصل، اللوكيشن).
- [ ] صياغة وضبط **الصفحات التعريفية والإلزامية وفق التجارة الإلكترونية السعودية**:
  - [ ] من نحن (قصة المتجر ورؤيته).
  - [ ] سياسة الاستبدال والاسترجاع (واضحة وقانونية).
  - [ ] سياسة الخصوصية والاستخدام.
  - [ ] الشحن والتوصيل.
- [ ] تفعيل ضريبة القيمة المضافة (VAT) إذا كان العميل مسجلاً فيها.
- [ ] تخصيص إشعارات الرسائل والبريد للعملاء (SMS / Email Notifications).

---

### 🔹 المرحلة 4: هيكلة الأقسام وإدخال المنتجات (Catalog & Copywriting)
- [ ] بناء شجرة التصنيفات والأقسام الرئيسية والفرعية.
- [ ] إضافة خيارات وسمات المنتجات (المقاس، اللون، الوزن، الحجم).
- [ ] رفع المنتجات مع كتابة نصوص تسويقية جذابة (Copywriting) توضح فوائد المنتج.
- [ ] ضبط تحسين محركات البحث لكل منتج (SEO Title & Meta Description).
- [ ] ضبط الأسعار وتكلفة المنتجات والعروض الترويجية وكميات المخزون.

---

### 🔹 المرحلة 5: الدفع والشحن (Payment & Shipping Integration)
- [ ] تفعيل **المدفوعات الإلكترونية عبر سلة باي (Salla Pay)**:
  - مدى (Mada)
  - أبل باي (Apple Pay)
  - فيزا / ماستركارد (Visa/Mastercard)
  - STC Pay
- [ ] تفعيل خيارات الدفع الآجل والتقسيط (تابي Tabby / تمارا Tamara) إذا كان مؤهلاً.
- [ ] إعداد خيار الدفع عند الاستلام (إن رغب العميل).
- [ ] تفعيل خيارات الشحن (سلة إكسبرس / أرامكس / سمسا / الشحن المخصص للرياض أو المدن الأخرى).
- [ ] تحديد تسعيرة الشحن والشحن المجاني عند الوصول لحد معين (مثلاً: شحن مجاني للطلبات فوق 299 ريال).

---

### 🔹 المرحلة 6: تخصيص الثيم وتصميم الصفحة الرئيسية (Theme & UX)
- [ ] اختيار وتفعيل أفضل ثيم متوافق مع نشاط المتجر.
- [ ] تخصيص ألوان الواجهة، الأزرار، والخطوط لتطابق الهوية.
- [ ] ترتيب عناصر الصفحة الرئيسية:
  - البانر الترويجي العلوي (اعلان متحرك أو شريط تنبيهات).
  - سلايدر العروض الرئيسية.
  - شريط المميزات (شحن سريع، دعم فني، دفع آمن).
  - شبكة الأقسام والتصنيفات.
  - بلوك المنتجات الأكثر مبيعاً / أحدث المنتجات.
  - بانر إعلاني وسطي (Call to Action).
  - آراء وتقييمات العملاء.
  - الفوتر (روابط الصفحات الهامة، حسابات التواصل، طرق الدفع المعتمدة، وسام التوثيق).

---

### 🔹 المرحلة 7: الفحص النهائي، التدريب والتسليم (Testing & Handover)
- [ ] اختبار مسار الطلب الكامل (إضافة للسلة -> إدخال عنوان -> دفع تجريبي -> تأكيد الطلب).
- [ ] اختبار توافق المتجر على شاشات الجوال بمختلف الأحجام.
- [ ] ربط وتفعيل الدومين المخصص (.com / .sa / .net) وفحص شهادة الأمان SSL.
- [ ] تجهيز دليل تسليم مختصر أو فيديو إرشادي للعميل لكيفية إدارة الطلبات وطباعة البوالص.
- [ ] التسليم الرسمي واستلام التقييم ومستحقاتك المالية بنجاح.
