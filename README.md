## 🏢 نبذة عن المؤسسة
**مؤسسة برق سهيل التجارية** هي الوجهة الأولى والرائدة في المملكة العربية السعودية (الدمام) المتخصصة في:
* أجهزة وهواتف الاتصالات الفضائية بالأقمار الصناعية (**الثريا - Thuraya**).
* أجهزة اللاسلكي البرية والبحرية المرخصة (**ICOM / Motorola / Kenwood**).
* أجهزة الملاحة وتحديد المواقع وتحديث خرائط الصحراء والبحار (**قارمن - Garmin GPS**).
* شرائح اتصال وبطاقات شحن رصيد الثريا الفوري.

📍 **المقر والمعرض:** الدمام - حي بدر 91 - طريق الملك فهد (داخل القناص الدولي).
