# 🌐 دليل تشغيل وتسليم موقع: مؤسسة برق سهيل التجارية (www.barqsuhail.com)

---

## 📁 محتويات مجلد الموقع (`D:\salla\website\`):
1. **`index.html`** ➔ الصفحة الرئيسية للموقع (واجهة الشركة الرسمية + كتالوج المنتجات + السلة + نموذج عروض الأسعار B2B + موقع الفرع بالدمام).
2. **`admin.html`** ➔ لوحة تحكم الإدارة (لإضافة وتعديل وحذف المنتجات ومتابعة طلبات عروض الأسعار).
3. **`assets/js/data.js`** ➔ قاعدة بيانات المنتجات الأولية.
4. **`assets/js/app.js`** ➔ منطق السلة التفاعلية والفلترة والربط مع الواتساب.
5. **`assets/images/`** ➔ كافة الصور والشعارات والبانرات الرسمية.

## ☁️ خطوات رفع الموقع على الدومين الرسمي (`www.barqsuhail.com`):
الموقع مبرمج كـ **(Static Web App)** جاهز للرفع على أي استضافة بدون الحاجة لقواعد بيانات معقدة:
* **عبر لوحة الاستضافة (cPanel):** ارفع محتويات مجلد `website` داخل مجلد `public_html`.
* **عبر استضافات مجانية/سريعة (Vercel / Netlify / Cloudflare Pages):** فقط اسحب المجلد `D:\salla\website` وسيعمل فوراً مع شهادة أمان SSL مجانية.
